# Финни — игра о финансовой грамотности для детей 7–11 лет

Android-приложение, в котором ребёнок заботится о виртуальном питомце Финни и на игровых решениях учится планировать бюджет, отличать нужное от желаемого, копить на мечту и оценивать свои траты.

Проект создан командой студентов для хакатона Департамента финансов города Москвы.

Подробное описание архитектуры, игровой логики и данных: [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md).

---

## Что умеет приложение

- **Обучение и создание питомца** — короткий туториал, выбор животного, цвета и имени.
- **Мечта** — ребёнок выбирает цель (игровая площадка, велосипед, телескоп) и копит на неё.
- **План дня** — 100 монет раскладываются по трём коробкам: «Нужно», «Хочется», «В копилку».
- **Магазин** — покупка еды, ухода и желаемых вещей; покупки влияют на сытость, уход и настроение Финни.
- **Копилка** — пополнение и снятие; перед снятием показывается, насколько отодвинется мечта.
- **Задания** — 24 интерактивных задания в трёх разделах: бюджет, сбережения, покупки.
- **Итоги дня** — сравнение плана и факта, оценка дня, рост питомца.
- **Раздел для взрослого** — чему учит игра, общий прогресс, демо-режим, сброс профиля.

Приложение работает **полностью офлайн**, не запрашивает разрешений и не собирает персональные данные.

## Локальный запуск

### 1. Скачать проект

```bash
git clone <ссылка-на-этот-репозиторий>
```

Или в Android Studio: **File → New → Project from Version Control**, вставить ссылку на репозиторий, нажать **Clone**.

### 2. Открыть в Android Studio

**File → Open** → выбрать папку проекта `FINNI`. Дождаться окончания **Gradle Sync** (первый раз может занять несколько минут — скачиваются зависимости). Если Android Studio предложит установить недостающий SDK — согласиться.

### 3. Запустить

**Вариант А — на телефоне:**
1. На телефоне включить *Режим разработчика* (Настройки → О телефоне → 7 раз нажать на «Номер сборки»).
2. В *Параметрах разработчика* включить **Отладку по USB**.
3. Подключить телефон кабелем, разрешить отладку во всплывающем окне.
4. Выбрать устройство в списке сверху в Android Studio и нажать **▶ Run** (Shift+F10 / ⌃R).

**Вариант Б — на эмуляторе:**
1. **Tools → Device Manager → Create Virtual Device**, выбрать любой телефон (например, Pixel 8) и образ Android 8.0+.
2. Запустить эмулятор и нажать **▶ Run**.

### 4. Сборка APK (по желанию)

В Android Studio: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

Или из терминала в корне проекта:

```bash
./gradlew assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Его можно скопировать на телефон и установить.

## Как быстро посмотреть всё приложение

1. Пройти обучение, создать Финни и выбрать мечту.
2. На главном экране нажать **«Составить план на день»** и разложить монеты.
3. Купить еду и уход в **Магазине**, отложить монеты в **Копилку**, выполнить пару **Заданий**.
4. Вернуться домой и нажать **«Завершить день»** — откроются итоги.
5. Чтобы начать заново: кнопка с родителями справа сверху → **«Для взрослого»** → сброс профиля.

## Структура проекта

```
app/src/main/
├── java/com/myau/finni/
│   ├── MainActivity.kt        — точка входа и навигация между экранами
│   ├── GameState.kt           — всё состояние игры в одном data class
│   ├── GameViewModel.kt       — игровые правила, единственный источник истины
│   ├── ProgressManager.kt     — сохранение прогресса на устройстве
│   ├── *Screen.kt             — экраны приложения
│   ├── TaskParser.kt, task.kt — загрузка заданий из assets/tasks.txt
│   ├── tasktypes/             — 6 типов интерактивных заданий
│   ├── UiKit.kt, NavButtons.kt, Coin.kt, Components.kt — общие элементы интерфейса
│   └── ui/theme/              — тема и цвета
├── assets/
│   ├── tasks.txt              — тексты и параметры 24 заданий
│   └── pets/                  — изображения питомцев
└── res/drawable/              — фоны, иконки, предметы
```
